# หุ่นยนต์ซูเปอร์มาร์เก็ตอัจฉริยะ (Smart Supermarket Picking AMR) – ร่างกติกา 2570

ภาพเคลื่อนไหว 3 มิติอธิบายกติกาการแข่งขัน: หุ่นยนต์ตัวอย่างทำภารกิจฝั่ง A ครบ 2 งาน และตัวอย่างการทำผิด 4 แบบ

กติกาที่ใช้ในภาพ: เวลาแข่ง 3 นาที · ใบคำสั่งซื้อเป็นบัตรสินค้า 5 ใบหนีบกับตะกร้า · ไม่มีคะแนนอ่านคำสั่งซื้อ · งานที่ 1 เต็ม 200 และโบนัสงานที่ 2 อีก 100

- คลิปสาธิต (MP4 2:37 นาที ไม่มีเสียง): `supermarket_robot_demo.mp4`

- เปิดดู: เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือเปิดผ่าน GitHub Pages: https://arejirawat.github.io/SupermaketRobotVEC/ (เมื่อเปิดใช้ Pages แล้ว)
- ควบคุม: เล่น/หยุด เลื่อนเวลา ปรับความเร็ว ข้ามไปแต่ละตอน ลากบนภาพเพื่อหมุนกล้อง ล้อเมาส์เพื่อซูม Shift+ลากเพื่อเลื่อน

หมายเหตุ: เป็นร่างกติกา ยังไม่ใช่ฉบับประกาศ รูปร่างหุ่นยนต์และเส้นทางเป็นเพียงตัวอย่างประกอบ
